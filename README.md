# Blood Bank Management System

A desktop-based Blood Bank Management System developed using **Python, Tkinter, and MySQL**.  
The application is designed to manage blood donors, blood inventory, blood requests, and related records through a simple graphical user interface.

## Features

- User Registration and Login
- Blood Donor Management
- Blood Group Management
- Blood Inventory Management
- Blood Request Management
- Search and Manage Blood Records
- Add, Update and Delete Records
- MySQL Database Integration
- User-friendly Graphical Interface
- Real-time database operations

## Technologies Used

- **Python**
- **Tkinter**
- **MySQL**
- **MySQL Connector for Python**
